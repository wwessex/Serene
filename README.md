# Serene

A mental wellness companion that feels like a trusted friend — not a clinical tool. Warm, private, and evidence-based.

## Features

- **Mood Tracker** — Daily emotional check-ins with streak tracking
- **Guided Journal** — CBT-based prompts in gratitude, reframe, and reflection modes
- **Breathe & Meditate** — Animated breathing exercises (Box, 4-7-8, Physiological Sigh)
- **Sleep Sanctuary** — Sleep quality logging, tips, and history tracking
- **CBT Toolkit** — Thought records and cognitive distortion identifier
- **Safe Space** — Community preview with crisis support resources

## Tech Stack

- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS v4** with custom warm earthy design system
- **localStorage** for client-side data persistence
- **Cormorant Garamond** + **DM Sans** typography

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design

- Warm cream background (#F5F0E8)
- Earthy accent palette with feature-specific colours
- Mobile-first responsive layout
- Animated breathing orb with real-time phase tracking
- Privacy-first: all data stays on your device

## Privacy Principles

- No data sold — ever
- No third-party advertising SDKs
- Journal entries stored locally only
- Full data control on your device
